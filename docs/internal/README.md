# Internal Documentation

This directory contains internal documentation for developers and maintainers.

## Structure

- **implementation-history/** - Historical records of completed features and implementations
- **plans/** - Implementation plans and specifications
- **build-reports/** - Docker build status and deployment reports
- **development-mode-guide.md** - Hot-reload development setup guide

## Purpose

These documents are for:
- Understanding implementation history
- Reference for debugging custom features
- Development workflow documentation
- Build and deployment tracking

## Note

These are internal documents and may not be kept up-to-date with the latest codebase.
For current documentation, see the main [docs/](../README.md) directory.
