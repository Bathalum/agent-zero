# Profile Management

## What are Profiles?
Profiles are persona configurations for the agent: name, description, avatar, and equipped skills (instruments).

## Switching Profiles
- Use the profile indicator in the left panel to open the quick switcher
- Click a profile to switch; the app reloads to apply changes
- Or open Settings → Profiles and click "Switch"

## Customizing Appearance
- Open Settings → Profiles → Edit on a profile
- Set display name, description, category
- Choose an avatar icon and color

## Equipping Skills
- In the profile editor, toggle instruments to assign/unassign
- Changes persist and influence recall behavior

## Creating Custom Profiles (Future)
- Planned: wizard and templates for new profiles

## Best Practices
- Keep descriptions concise and task-oriented
- Group instruments by the profile’s role
- Use distinct avatars/colors for quick recognition

## Troubleshooting
- No profiles listed: ensure `agents/` folders exist and are readable
- Switch fails: check server logs and that profile folder exists
- Icons not visible: confirm CSS loaded and icon class names are correct
